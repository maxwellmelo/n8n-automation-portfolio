Personal AI Assistant

Multi-purpose AI assistant that handles tasks, reminders, scheduling and answers questions via WhatsApp and Telegram with intelligent learning capabilities.

AI-Powered Multi-Platform Learning 35+ nodes

Overview

The Personal AI Assistant is your intelligent companion for daily tasks and productivity. This workflow creates a versatile assistant accessible via WhatsApp and Telegram that not only responds to your questions but actively helps you manage your life - from setting reminders and scheduling appointments to answering complex questions and learning your preferences over time.

Unlike simple chatbots, this assistant integrates with multiple services, maintains context across conversations, and adapts to your communication style. It's designed to be proactive, sending you timely reminders and suggestions based on your patterns and preferences.

Key Features

Task Management

Create, track and complete tasks using natural language commands.

Smart Reminders

Set recurring or one-time reminders with intelligent timing suggestions.

Schedule Coordination

Manage appointments and events with automatic conflict detection.

Intelligent Q&A

Get accurate answers powered by advanced AI language models.

Service Integration

Connects with Google Calendar, Todoist, Notion and more services.

Preference Learning

Adapts to your habits and preferences through machine learning.

Technical Requirements

  • Self-hosted n8n instance or n8n Cloud account
  • OpenAI API key for GPT-4 access
  • PostgreSQL or MongoDB for user data storage
  • WhatsApp Business API or Evolution API
  • Telegram Bot Token (optional, for Telegram support)
  • Google Cloud account for Calendar integration
  • Todoist API key (optional, for task management)
  • Notion API key (optional, for notes and databases)

How to Use

  • Import the workflow JSON file into your n8n instance
  • Configure all required credentials (OpenAI, database, messaging platforms)
  • Set up your database schema using the provided migration scripts
  • Customize the AI system prompts to match your preferences
  • Configure webhook URLs in WhatsApp/Telegram settings
  • Activate the workflow and send your first message
  • Train the assistant by providing feedback on responses
  • Enable optional integrations (Todoist, Notion, etc.) as needed
