## Descrição

Transcritor de consultas médicas com IA:
- Transcrição de áudio de consultas
- Extração estruturada de dados médicos
- Identificação de sintomas e diagnósticos
- Correção de nomes de medicamentos

## Categorias

Healthcare, AI, Transcription

## Configuração

### Credenciais Necessárias

Procure por placeholders no workflow e configure:
- `DEMO_*` - IDs de credenciais
- `SUA_*` - Chaves de API
- `seu-*` - URLs e domínios

### Passos

1. Importe o arquivo JSON no n8n
2. Acesse cada node com erro de credencial
3. Configure suas próprias credenciais
4. Ajuste URLs e parâmetros conforme necessário
5. Teste com dados de exemplo
