## Descrição

Chatbot WhatsApp completo com IA:
- Integração Z-API/Evolution para WhatsApp
- Processamento de texto, áudio e imagens
- IA conversacional com OpenAI (GPT-4)
- Memória de contexto com Redis
- Detecção de intervenção humana
- Sistema de botões interativos
- Auditoria em Google Sheets

## Categorias

WhatsApp, AI, Chatbot

## Configuração

### Credenciais Necessárias

Procure por placeholders no workflow e configure:
- `DEMO_*` - IDs de credenciais
- `SUA_*` - Chaves de API
- `seu-*` - URLs e domínios

### Passos

1. Importe o arquivo JSON no n8n
2. Acesse cada node com erro de credencial
3. Configure suas próprias credenciais
4. Ajuste URLs e parâmetros conforme necessário
5. Teste com dados de exemplo
