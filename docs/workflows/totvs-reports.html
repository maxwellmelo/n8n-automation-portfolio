TOTVS RM Report Generator

Automated report generation system from TOTVS RM ERP with scheduled delivery via email and WhatsApp in multiple formats.

TOTVS RM PDF Excel 25+ nodes

Overview

The TOTVS RM Report Generator is a comprehensive automation solution that connects directly to your TOTVS RM ERP system to extract, process, and deliver critical business reports. This workflow eliminates manual report generation, ensuring stakeholders receive accurate data on time, every time.

Designed for businesses that rely on TOTVS RM for operations, this workflow streamlines the reporting process by automating data extraction, formatting, and distribution. Whether you need daily sales summaries, inventory reports, or financial statements, this solution handles it all with minimal configuration.

Key Features

Scheduled Generation

Configure reports to run daily, weekly, monthly, or on custom schedules automatically.

Multiple Formats

Export reports as PDF, Excel, CSV, or JSON based on recipient preferences.

Multi-Channel Delivery

Distribute reports via email, WhatsApp, Slack, or save to cloud storage automatically.

Dashboard Integration

Push real-time data to business intelligence dashboards and analytics platforms.

Dynamic Filtering

Apply custom filters, date ranges, and parameters to generate targeted reports.

Secure Connections

Encrypted connections to TOTVS RM with role-based access control and audit logs.

Technical Requirements

  • Self-hosted n8n instance or n8n Cloud account
  • TOTVS RM ERP with API access enabled
  • Valid TOTVS RM credentials with read permissions
  • SMTP server or email service (Gmail, SendGrid, etc.)
  • Optional: WhatsApp Business API (Evolution API or Z-API)
  • Optional: Cloud storage (Google Drive, Dropbox, AWS S3)
  • Optional: Dashboard integration (Power BI, Tableau, Metabase)

How to Use

  • Import the workflow into n8n (Settings - Import from File/URL)
  • Configure TOTVS RM API credentials and connection settings
  • Set up email service credentials (SMTP or provider API)
  • Configure report schedules using Cron expressions or simple intervals
  • Define recipient lists and delivery preferences (email, WhatsApp, storage)
  • Customize report templates and filters based on your business needs
  • Test the workflow manually before activating scheduled execution
  • Monitor execution logs and adjust parameters as needed
