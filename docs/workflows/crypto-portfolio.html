Crypto Portfolio Analyzer

Advanced cryptocurrency portfolio tracker with real-time PnL calculation, ROI analysis, multi-wallet support and automated performance reports.

Real-time Multi-Wallet Reports 35+ nodes

Overview

The Crypto Portfolio Analyzer is a comprehensive solution for tracking and analyzing cryptocurrency investments across multiple wallets and exchanges. This workflow provides real-time portfolio valuation, profit and loss calculations, ROI metrics, and automated performance reports.

Whether you're managing a personal portfolio or tracking investments for clients, this automation delivers professional-grade analytics with support for hundreds of cryptocurrencies, multiple fiat currencies, and customizable reporting schedules.

Key Features

Multi-Wallet Tracking

Track unlimited wallets and exchange accounts in one unified portfolio view.

Real-time Valuation

Live price feeds from CoinGecko and CoinMarketCap for accurate portfolio valuation.

PnL Calculation

Automatic profit and loss calculation with detailed breakdowns by asset and time period.

ROI Analysis

Calculate return on investment with support for multiple cost basis methods (FIFO, LIFO, Average).

Portfolio Allocation

Visual breakdown of portfolio composition with percentage allocation by asset.

Performance Reports

Automated daily, weekly, or monthly reports via email, Telegram, or Slack.

Technical Requirements

  • Self-hosted n8n instance (v1.0+)
  • PostgreSQL or Redis database for portfolio data storage
  • CoinGecko API or CoinMarketCap API key (free tier supported)
  • Exchange API credentials (Binance, Coinbase, Kraken, etc.) - optional
  • Blockchain explorer APIs (Etherscan, BscScan, etc.) for wallet tracking
  • Email account (SMTP) or messaging platform credentials for reports

How to Use

  • Import the workflow JSON into your n8n instance
  • Configure your wallet addresses and exchange API credentials
  • Set up price data provider (CoinGecko or CoinMarketCap)
  • Configure database connection for portfolio history
  • Customize report format and delivery channels (email, Telegram, Slack)
  • Set up scheduling intervals (recommended: hourly for tracking, daily for reports)
  • Activate the workflow and receive your first portfolio report
  • Optional: Configure cost basis method (FIFO, LIFO, or Average Cost)
