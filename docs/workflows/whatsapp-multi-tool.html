WhatsApp Multi-Tool AI Assistant

Complete assistant with GPT-4, Google Calendar integration, Gmail and intelligent reminder system via WhatsApp.

GPT-4 Whisper Vision 40+ nodes

Overview

The WhatsApp Multi-Tool AI Assistant is the most complete solution for creating an intelligent virtual assistant via WhatsApp. Combining the power of GPT-4 with productivity integrations, this workflow transforms conversations into automated actions.

Key Features

Intelligent Conversation

GPT-4 with context memory for natural and accurate responses.

Audio Transcription

OpenAI Whisper automatically converts voice messages to text.

Image Analysis

GPT-4 Vision interprets photos and documents sent.

Google Calendar

Create, edit and query events using natural language.

Gmail Integration

Read, send and manage emails directly from WhatsApp.

Reminder System

Schedule reminders that are automatically sent.

Technical Requirements

  • Self-hosted n8n instance
  • OpenAI account with access to GPT-4, Whisper and Vision
  • Redis server for conversation memory
  • Evolution API or Z-API for WhatsApp Business
  • Google Cloud account (for Calendar and Gmail)

How to Use

  • Import the workflow in n8n (Settings - Import)
  • Configure credentials (OpenAI, Redis, Evolution API, Google)
  • Replace placeholders with your data
  • Activate the workflow and send a test message
  • Customize the system prompt as needed
