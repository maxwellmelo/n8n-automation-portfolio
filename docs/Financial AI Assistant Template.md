## Descrição

Assistente financeiro inteligente via WhatsApp:
- Consultas a banco de dados SQL
- Análise financeira com IA
- Transcrição de áudio
- Análise de imagens e documentos
- Memória de conversa
- Ferramentas: calculadora, consultas SQL

## Categorias

Finance, AI, WhatsApp, Database

## Configuração

### Credenciais Necessárias

Procure por placeholders no workflow e configure:
- `DEMO_*` - IDs de credenciais
- `SUA_*` - Chaves de API
- `seu-*` - URLs e domínios

### Passos

1. Importe o arquivo JSON no n8n
2. Acesse cada node com erro de credencial
3. Configure suas próprias credenciais
4. Ajuste URLs e parâmetros conforme necessário
5. Teste com dados de exemplo
