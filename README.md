Portfólio profissional de automações n8n desenvolvido por Maxwell Melo. Este site apresenta 16 templates de workflows avançados com integrações de IA, WhatsApp, análise de dados e muito mais.

## 🚀 Destaques

- **16 Templates de Workflows** profissionais prontos para uso
- **500+ Nós** distribuídos em automações complexas
- **15+ Integrações** com serviços populares (GPT-4, WhatsApp, Google Workspace, etc.)
- **Design Moderno** com tema escuro e gradientes profissionais
- **100% Responsivo** para todos os dispositivos

## 📁 Estrutura do Projeto

